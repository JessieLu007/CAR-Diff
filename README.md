# CAR-Diff

CAR-Diff is a DDPM-based synthesizer for mixed-type (numerical + categorical) tabular data,
targeting imbalanced clinical datasets. Categorical columns are generated by an autoregressive
head conditioned on the diffused numerical representation.

## Environment

Two options depending on what you need:

**Option A — generation only (fit / sample).** Lightweight.

```bash
conda create -n car-diff python=3.11
conda activate car-diff
bash install-core.sh          # auto-detects GPU/CPU; see install-core.sh for options
```

With this environment, `quickstart.py eval` and `quickstart.py baselines` will fail with an
`ImportError` — they need Option B.

**Option B — generation + evaluation + baselines.** `synthcity` pulls in a large dependency tree
(transformers, pytorch-lightning, and a few unrelated libraries); a fresh install can take 20–60+
minutes and download 1–2 GB.

```bash
conda create -n car-diff python=3.11
conda activate car-diff
bash install.sh          # auto-detects GPU/CPU; see install.sh for options
```

## Quick Start

1. Put your data at `data/<name>.csv`.
2. Declare its columns in `data/datasets_info.json`:

```json
{
  "my_dataset": {
    "numerical":   ["age", "bp"],
    "categorical": ["sex", "stage"],
    "target": "label",
    "minority_class": "positive"
  }
}
```

`target` is optional; when given, it is modeled jointly with the other categorical columns and used
for evaluation (TSTR, SHAP). `minority_class` is optional; if omitted, the least frequent class in
the training data is used.

3. Fit, sample and evaluate in one command:

```bash
python quickstart.py run --dataset my_dataset --test-size 0.2 --repeats 5
```

This splits off 20% of the data as a held-out test set, trains the model, draws 5 synthetic samples,
and evaluates **all of them**, reporting mean±std per metric (saved to `runs/my_dataset/eval_mean_std.csv`).
If you already have a separate test file, pass `--test my_test.csv` instead of `--test-size`.

Step by step:

```bash
python quickstart.py fit    --dataset my_dataset --test-size 0.2
python quickstart.py sample --dataset my_dataset --repeats 5
python quickstart.py eval   --dataset my_dataset --all                     # all synthetic_s*.csv, mean±std
python quickstart.py eval   --dataset my_dataset --fake runs/my_dataset/synthetic_s1.csv  # single sample
```

Comparison methods (SMOTE / CTGAN / TVAE / TabDDPM):

```bash
python quickstart.py baselines --dataset my_dataset --methods smote ctgan --n-samples 5
python quickstart.py eval --dataset my_dataset --fake runs/my_dataset/baselines/smote_s0.csv
```

Common overrides: `--epochs`, `--seed`, `--model "dim_hidden=128"`, `--training "batch_size=32"`.
Full option list: `python quickstart.py --help`.

For anything not covered here — custom files instead of `--dataset`, output layout, what each
metric means — read `quickstart.py`'s module docstring and `evaluation/metrics.py`; they're the
source of truth.

## Reproducing the Paper (five-fold CV)

The fold indices ship with the repo (`splits/*_5fold.json`); imputed splits and `data/Info/` are
generated by `run_cv`, so run it before `gen_baselines` / `prepare_tabsyn_folds`. Splitting uses a
fixed seed (2026) but depends on the scikit-learn version, so results may differ slightly in other
environments.

```bash
# Ours (autoregressive categorical head, the paper's main result)
python -m experiments.run_cv --dataset chronic_kidney_disease --fold 0 1 2 3 4 \
    --tag main --model "cat_ar=True" --train "target_epochs=200" --seed 42
# Ablation: w/o AR
python -m experiments.run_cv --dataset chronic_kidney_disease --tag noar --model "cat_ar=False"

# Repeated sampling (s1..s4; s0 comes from training)
python -m experiments.resample_ours --dataset chronic_kidney_disease --device cuda --js 1 2 3 4

# Comparison methods, looped over folds
for k in 0 1 2 3 4; do
  python -m evaluation.gen_baselines --dataset chronic_kidney_disease --fold $k \
      --methods smote ctgan tvae tabddpm tabkde --n-samples 5
done

# Evaluation and aggregation
python -m evaluation.run --dataset chronic_kidney_disease --fold 0 1 2 3 4 --hp h256_t200_3_main \
    --baselines smote ctgan tvae tabddpm tabkde
python scripts/aggregate_main.py
```

Result folders and tags keep their experiment-time names: `ours_h256_t200_3_main` is reported as
**Ours**, `ours_h256_t200_3_noar` as **w/o AR**. Other ablations (legacy / sampled / nointeract) use
an older code version — `git checkout ablation-cat-switches` — and the w/o AR variant corresponds to
tag `experiments-final`. See each script's `--help` for the remaining flags.

## TabKDE and TabSyn

Not bundled (license/size); set up once, then they slot into the five-fold pipeline above.

- **TabKDE**: `bash third_party/tabkde/setup_tabkde.sh <official zip>`, then
  `python -m evaluation.make_tabkde_info`.
- **TabSyn**: `bash third_party/tabsyn/setup_tabsyn.sh <official zip>` (official repo:
  https://github.com/amazon-science/tabsyn, Apache-2.0; default hyperparameters), then
  `python -m experiments.prepare_tabsyn_folds --dataset <name> [--all] --seed 2026 --n_folds 5`.
  Evaluate with `evaluation.run --tabsyn-root third_party/tabsyn/tabsyn-main`.

## Notes

- `libgomp: Invalid value for environment variable OMP_NUM_THREADS` is fixed automatically by
  `quickstart.py`; for other scripts, `export OMP_NUM_THREADS=8` first.
- `evaluation/gen_baselines.py` imports `synthcity` at the top, so it must be installed even if
  you only run SMOTE.
